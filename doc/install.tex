
\section{Getting TPG}

TPG is freely available on its web page (\url{https://cdelord.fr/tpg}). It is distributed as a package using \emph{distutils}\footnote{distutils is a Python package used to distribute Python softwares}.

\section{Requirements}

TPG is a \emph{pure Python} package.
It may run on \emph{any platform} supported by Python.
The only requirement of TPG is \emph{Python~3.9} or newer. Python can be downloaded at \url{https://www.python.org}.

\section{Installation}

There is no specific installation procedure.
Just download TPG and copy \emph{tpg.py} to your project:
\begin{quote}
\begin{verbatim}
    git clone https://codeberg.org/cdsoft/tpg
    cp tpg/tpg.py path/to/your/project/
\end{verbatim}
\end{quote}
